# كاستر ستور — تطبيق متجر (أندرويد / iOS)

تطبيق Expo (React Native) + Supabase. واجهة عربية RTL.

## المزايا
- **شاشة افتتاحية** متحركة عند فتح التطبيق، ثم الواجهة الرئيسية.
- **20 قسماً** بلا تكرار: الأكثر مبيعاً، عروض خاصة ومنتجات موسمية، الأجهزة الإلكترونية، الأجهزة الكهربائية والمنزلية، الأثاث المنزلي والديكور، مستلزمات المطبخ، مستحضرات التجميل والعناية، أدوات الحلاقة والعناية الشخصية، مباخر وملطفات الجو، مستلزمات السيارات، الصحة والرياضة، ألعاب وهوايات، ملابس وأكسسوارات، جديد، إنارة وإضاءة، عدد وأدوات، النظارات، كوزمتك، ساعات رجالية، ساعات نسائية.
- شريط سفلي (من اليمين): **الرئيسية • الأقسام • السلة • طلباتي • الدعم • الإعدادات**.
- الزائر يتصفح فقط. الشراء والدعم يحتاجان حساباً.
- **الحساب:** إنشاء بالهاتف (يمين) أو Gmail (يسار) مع تأكيد كلمة المرور، وتحتهما تسجيل الدخول بالبريد أو الهاتف. الحساب محفوظ على الخادم فيمكنك الدخول بعد حذف التطبيق وتثبيته.
- **الطلب:** السلة (تحديد الكمية) ← إكمال ← الاسم الثلاثي + الهاتف + هاتف اختياري + ملاحظات للمندوب ← إكمال ← المحافظة + المنطقة + أقرب نقطة دالة ← تأكيد الطلب، وينتقل فوراً إلى «طلباتي».
- **حالات الطلب:** قيد المراجعة ← قيد التغليف ← قيد التوصيل ← تم التوصيل، أو تم الرفض مع سبب يراه الزبون. المالك يغيّرها في أي وقت من تبويب «الطلبات».
- **الدعم:** محادثة سرية (نص + صور) بين كل مستخدم والمالك. عند المالك يظهر كل من راسله كملف شخصي (مثل ماسنجر) ويدخل محادثته ويرد.
- **الإشعارات (بصوت):** للمالك عند طلب جديد أو رسالة. للمستخدم عند رد المالك أو تغيير حالة طلبه. والمالك يرسل إعلاناً للجميع. صندوق إشعارات داخل التطبيق (زر 🔔 في الرئيسية).
- **أصوات الإشعارات:** المالك يختار صوتاً لكل نوع (الإعدادات ← أصوات الإشعارات) ولكل إعلان على حدة.
- **المنتجات (للمالك):** إضافة/تعديل/حذف، صور وفيديوهات بلا حدّ، وصف طويل، روابط اختيارية، تفعيل/إخفاء، «الأكثر مبيعاً».
- **توصيل مجاني:** شريط بارز في الرئيسية، ويظهر «مجاني» في السلة. لتفعيل رسوم توصيل غيّر `STORE.deliveryFee` في `src/config.js`.
- **الاستبدال فقط:** لا يوجد إرجاع. الاستبدال بنفس المنتج عند وجود عيب، **خلال يومين من الاستلام** ولا يمكن في اليوم الثالث (مكتوب في صفحة المنتج وفي شروط الاستخدام).
- **الإعدادات:** الاسم، تغيير كلمة المرور (تشمل حساب المالك)، **المظهر (تلقائي / فاتح / داكن)**، الإشعارات، الإصدار 1.0.0، شروط الاستخدام، سياسة الخصوصية، فيسبوك، مشاركة، تسجيل الخروج، **حذف الحساب**.
- **حذف الحساب:** نهائي، ولا يمكن فتح الحساب المحذوف مرة أخرى. تُحذف بيانات الحساب والمحادثات والإشعارات، ويبقى سجل الطلبات للمحاسبة دون ربطه بصاحبه. حساب المالك لا يُحذف.

- **لافتة إشعار فورية:** عند وصول أي إشعار والتطبيق مفتوح تظهر لافتة أعلى الشاشة مع الصوت المختار (تعمل حتى في Expo Go). والتطبيق مغلق يصل إشعار النظام بالصوت (يحتاج نسخة EAS).

- **شعار التطبيق:** أيقونة التطبيق وشاشة البداية وأيقونة الإشعار من شعارك (`assets/`).
- **أصوات من جهازك:** الإعدادات ← أصوات الإشعارات ← «رفع صوت من الجهاز». تعمل كاملة عند فتح التطبيق؛ والتطبيق مغلق يُستخدم صوت مضمّن بديل لأن النظام يشترط ذلك.
- **تعديل/حذف الإشعارات المنشورة:** الإعدادات ← لوحة المالك ← «الإشعارات المنشورة».
- **الضغط على الإشعار** يفتح التطبيق على الشاشة المناسبة حتى لو كان مغلقاً.
- بعد التحديث: شغّل `schema.sql` مجدداً، ثم `npm install`، وأعد `supabase functions deploy notify`، وأعد بناء EAS.

## الإعداد (مرة واحدة)

### 1) Supabase
1. أنشئ مشروعاً مجانياً على supabase.com.
2. SQL Editor ← الصق محتوى `supabase/schema.sql` ← Run.
3. Authentication ← Providers ← Email ← **عطّل "Confirm email"** (ضروري ليعمل الدخول بالهاتف).
4. Project Settings ← API ← انسخ **Project URL** و **anon key** إلى `src/config.js`.
5. انشر دالة الإشعارات:
   ```bash
   npm i -g supabase
   supabase login
   supabase link --project-ref <معرّف-مشروعك>
   supabase functions deploy notify
   ```

### 2) حساب المالك (مخفي)
1. بعد `schema.sql` الصق محتوى `supabase/create-owner.sql` في SQL Editor ← Run.
2. هذا ينشئ حساب المالك مسبقاً بالبريد `2009OmerMohammed12@gmail.com` وبكلمة المرور التي زوّدتني بها، لكنها محفوظة كـ**بصمة bcrypt** فقط (لا يمكن استخراج كلمة المرور منها).
3. لا يظهر أي شيء عن المالك داخل التطبيق، والبريد محجوز فلا يستطيع أحد تسجيله، ولا توجد ترقية تلقائية بالبريد.
4. سجّل الدخول بالبريد وكلمة المرور من شاشة تسجيل الدخول العادية، ثم غيّر كلمة المرور من الإعدادات.
> كلمة المرور كُتبت في المحادثة، لذا يُنصح بتغييرها فوراً من الإعدادات.

### 3) التشغيل
```bash
npm install
npx expo start
```
التصفح والطلبات والدردشة تعمل في **Expo Go**. الإشعارات بأصواتك المخصصة تحتاج نسخة مبنية (الخطوة 4).

### 4) بناء نسخة بالإشعارات والأصوات
```bash
npm i -g eas-cli
eas login
eas init                      # ضع projectId الناتج في app.json ← extra.eas.projectId
eas build -p android --profile preview   # ملف APK للتجربة
```
- **أندرويد:** إشعارات Push تحتاج مفتاح Firebase (FCM). أنشئ مشروع Firebase، نزّل `google-services.json`، وأضفه عبر `eas credentials` (راجع توثيق Expo: Push notifications → FCM credentials).
- **iOS:** يحتاج حساب Apple Developer.

## الأصوات
`assets/sounds` فيها 8 أصوات + الافتراضي. لإضافة صوت: ضع ملف `.wav`، أضفه في `src/sounds.js` وفي `app.json` (قسم sounds)، ثم أعد البناء. أصوات الإشعارات لا يمكن رفعها أثناء التشغيل لأن النظام يتطلب أن تكون ضمن ملفات التطبيق.

## ملاحظات
- الدخول بالهاتف يتم داخلياً عبر بريد وهمي (`رقم@phone.casterstore.app`) لتجنب رسوم الرسائل النصية. نتيجة ذلك: لا توجد استعادة كلمة مرور بالرسائل. للبريد الحقيقي يمكن تفعيل الاستعادة لاحقاً.
- أقصى حجم للملف الواحد في الخطة المجانية لـ Supabase 50MB (فيديوهات قصيرة).
- شروط الاستخدام والخصوصية في `src/legal.js` نصوص عامة، راجعها وعدّلها قبل النشر.
- الدفع عند الاستلام فقط. لا توجد بوابة دفع إلكتروني.
- رسوم التوصيل: `src/config.js` ← `STORE.deliveryFee`.
